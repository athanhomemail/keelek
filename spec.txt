ระบบคีย์เลขหวย
ชื่อระบบ Kee-Lek (คีย์เลข)
โทนระบบจะเป็นสี มืดๆ ส้มๆ ทองๆ อะไรประมาณนี้
ระบบนี้จะต้องรองรับหน้าจอมือถือ เพราะส่วนใหญ่จะใช้บนมือถือผ่าน Line กัน

front ทั้งระบบ Mitr

Tech Stack
- frontend : reactjs + vite + tailwindcss + axios + socket.io
- backend : nodejs express + socket.io
- database : mysql(รันผ่าน docker) เขียน databasename ตามชื่อระบบ เพราะอนาคตเราจะมีหลายๆระบบจะแยก database ตามชื่อระบบ
Docker ให้รันแค่ MySql พอ

Folder Structure
- keelek (Folder) <- root
-- backend (Folder) จะต้องรันด้วยคำสั่ง "npm start"
-- frontend (Folder) จะต้องรันด้วยคำสั่ง "npm start"
-- SQLSchema (Folder)
-- Docker (Folder)

ช่วยทำ docker compose และ sql schema ให้ด้วย

คือเรามีเช่า Server Host VPS ไว้แล้ว
และมีซื้อ Domain ไว้แล้ว
Domain เรามีอยู่สอง Domain 
- twiniiz.com
- kuayrai.com

เราเลยอยากให้สร้าง MySQL Container แยกชื่อตาม domain
เพราะเราจะแยกระบบในนั้นด้วย
เช่น 
domain : twiniiz รันระบบ testsystem1, testsystem2 ใน MySQL Container ของ twiniiz ก็จะมี databasename testsystem1, testsystem2
domain : kuayrai รันระบบ keelek ใน MySQL Container ของ kuayrai ก็จะมี databasename keelek
อะไรประมาณนี้
อย่างระบบนี้ก็จะไปอยู่ใน domain : kuayrai

ระบบนี้เอาไว้ทำอะไร
ระบบนี้เพื่อเอาไว้ให้ เจ้ามือหวยแต่ละเจ้ามาเช่าไปใช้งานในการคีย์ เก็บข้อมูล แจ้งเตือนใน Line OA ออกบิลให้ลูกค้า เพื่อให้สะดวกขึ้นอะไรประมาณนั้น สามารถ "โหลด" บิลเป็นรูปภาพได้เพื่อส่งไปให้ลูกค้า
แสดงว่าในระบบจะมีหลายๆเจ้ามือหวยเข้ามาใช้งาน
ระบบนี้มีไว้เพื่อให้เจ้ามือหวยมาคีย์เลขที่ลูกค้าซื้อกับตน
แต่ละงวดมีลูกค้าคนไหนเลขอะไรจำนวนเท่าไหร่ มีบิลกี่บิล
เอาไว้ออกบิลให้ลูกค้า ดูว่าบิลนั้นประกอบไปด้วย งวดไหนวันที่เท่าไหร่เวลาอะไรที่ซื้อ อัตราการจ่ายเท่าไหร่ในแต่ละเลขที่ซื้อประเภทหวยที่ซื้อ
ประเภทหวยจะมี หวยไทย, ลาว
สามารถดู report สรุปได้ว่าในแต่ละงวดมียอดที่ต้องจ่ายลูกค้าเท่าไหร่ จ่ายใครบ้าง มีกำไรเท่าไหร่ อะไรปรมาณนี้ สามารถติ๊กได้ว่าลูกค้าคนไหนจ่ายแล้วหรือยังไม่จ่าย ค้างจ่ายงวดไหนบ้าง
ระบนี้ทำเพื่อรองรับหลายๆเจ้ามือหวย แต่ละเจ้าก็จะมีคนในทีมภายใต้ของตัวเอง ระบบนี้จะแบ่งเป็นของแต่ละเจ้ามือหวยจะไม่ยุ่งเกี่ยวกัน
ระบบนี้จะเล่นกับ Line OA เราจะต้องทำรองรับ Line OA
เราจะขอให้คำเรียกแบบนี้แล้วกันนะ

ระบบนี้จะมีหลายๆห้องคีย์
ใน "ห้องคีย์" จะประกอบไปด้วย
- หัวหน้า (เจ้ามือหวย)
- สมาชิก (ลูกทีม)

Line แต่ละคนก็จะผูกกับห้องคีย์เพียงห้องเดียวเท่านั้น สิทธิ์ในการทำงานก็จะมี หัวหน้า และสมาชิก
และมีระบบ Web Scraper เพื่อเอาดึงหวยจากเว็บอื่นๆมาเก็บไว้ในฐานข้อมูลเรา เช่นทุกๆวันที่ 1 หรือ 16 เวลา 16:00 ก็ไปเข้าเว็บ ... เพื่อไปดึงข้อมูลเลขที่ออกของหวยไทยมาเก็บไว้
แล้วระบบก็จะได้แสดงหวยที่ออกและสรุปบิลแต่ละบิลว่าใครถูก ใครได้ใครเสียให้เลย
หัวหน้าแต่ละห้องสามารถกำหนดอัตราการจ่ายของแต่ห้องได้ เช่น หวยประเภทไหนได้บาทละเท่าไหร่ มีการกำหนดจ่ายเต็มจ่ายครึ่งในแต่ละงวดได้ หรือสามารถกำหนดได้ว่าในแต่ละงวดแต่ละเลขแต่ละประเภทรับได้ไม่เกินกี่บาท หรือเลขไหนไม่รับเลย

- เป็นสมาชิก - สมาชิก : คีย์เลข, สรุปบิล, ทีม

การทำงานตอนแรกเลยนะสำหรับคนที่จะมาขอเช่าระบบ
หลังจากกดเข้าระบบ ระบบจะเด้งให้ แอดเพื่อน Line OA ก่อน
หลังจาก Add Line OA ไปแล้ว
ระบบจะไปหาก่อนเลยว่า Line นี้เป็นสมาชิคแล้วหรือยัง
ถ้ายังไม่เป็นระบบจะกำหนด Rich Menu เป็น Rich Menu เริ่มต้นคือแบบ "ยังไม่เป็นสมาชิก" ให้อัตโนมัติ
ใน Rich Menu แบบ "ยังไม่เป็นสมาชิก" จะมีให้กดแค่ เมนูเดียวเลยคือ "ห้องคีย์"
ถ้า user กด "ห้องคีย์" จะแสดง Line LIFF ขึ้นมาเป็นหน้าระบบให้เลือกระหว่าง "สร้างห้อง" หรือ "เข้าร่วม"(join ห้อง)
- ถ้า user เลือก "สร้างห้อง" หน้าระบบก็จะขึ้นข้อมูลให้กรอกนิดหน่อยเช่นชื่อจริง-นามสกุล ชื่อเล่น เบอร์โทร บัญชีธนาคาร หรือ พร้อมเพย์ อะไรพวกนี้ แล้วกด submit 
หลังจากกด submit (ก็รอทาง admin Approve หรือ Reject) ระบบจะส่งข้อความไปทาง Admin  ประมาณว่ามีคนต้องการจะสร้างห้อง 
ถ้า Admin Approve คนนั้นก็จะได้เป็นหัวหน้าทันนี้ และ Rich Menu ของ user คนนั้นก็จะเปลี่ยนไปเป็นแบบ "เป็นสมาชิก - หัวหน้า" จะประกอบไปด้วย เมนู คีย์เลข, สรุปบิล, ทีม, ตั้งค่า
และจะมีข้อความ Rich Message ส่งไปบอกว่า Admin ได้อนุมัติแล้ว ตอนนี้คุณได้เป็นหัวหน้า อะไรประมาณนั้น

- ถ้า user เลือก "เข้าร่วม" หน้าระบบจะมี textbox 6 box เรียงติดกัน ให้กรอกรหัสเข้าร่วม "ห้อง"
รหัสจะเอามาจากไหน รหัสห้องจะเอามาจาก หวัหน้าห้องเท่านั้น หัวหน้าห้องจะเป็นคนบอกรหัสให้กรอกเอง รหัสจะเป็นรหัส 6 หลักที่สุ่ม 0-9 ผสมกับ A-Z
หัวหน้าห้องจะต้องเอารหัสจาก เมนู ทีม -> ในหน้าระบบของทีม จะมีแสดงรหัสของห้องนั้นอยู่ 6 หลัก
ถ้าลูกทีมกรอกรหัสห้องและกด submit ลูกทีมต้องรอให้ หัวหน้าห้องกดยืนยันก่อน
จะมีข้อความส่งไปให้ทางหัวหน้าห้องว่ามี User ต้องการขอเข้าร่วมห้อง จะเป็น Rich Message ประกอบไปด้วย ชื่อ Line รูปโปรไฟล์ มีให้กด ยืนยัน และยกเลิก
ถ้ายืนยัน Rich Menu ของ User ที่ขอเข้าร่วมก็จะเปลี่ยนไปเป็นแบบ "เป็นสมาชิก - สมาชิก" ประกอบไปด้วยเมนู คีย์เลข, สรุปบิล, ทีม
การสร้างห้อง, หัวหน้า, สมาชิก ก็จะประมาณนี้

เมนู : คีย์เลข
เมนูนี้คือหัวใจสำคัญใการกรอกข้อมูลเลขหวยเลย
หลังจากกดเข้าเมนูนี้แล้วจะแสดง Line Liff เด้งหน้าระบบขึ้นมา ให้เลือกว่าต้องการคีย์ หวยไทย, ลาว อาจจะเป็น ปุ่มใหญ่ๆสองปุ่มวางข้างๆกันให้เลือกก็ได้
หลังจากเลือกเข้าไปแล้วก็จะขึ้นรายละเอียดงวดปัจจุบันที่ยังไม่ออกผลให้คีย์ และจะมีเวลานับถอยหลังของการรับบิลในแต่ละงวดนั้นๆ 
จะมีปุ่มแบบกรอกรัด ปุ่มช่วยกรอกเช่น เลขวิ่ง เลขกลับ บน ล่าง อะไรพวกนี้เราก็ไม่รู้ว่ามันมีปุ่มช่วยกรอกอะไรบ้าง
มีให้กรอกยอด กรอกเลข ใส่ชื่อลูกค้า และจะมีอัตราจ่าย/บาทแสดงหลังตัวเลข 
และแต่ละตัวเลขก็จะมีแสดงยอดจำนวนเงินที่ยังสามารถรับซื้อได้ว่าเหลือเท่าไหร่ แบบ realtime (socket.io) เพราะถ้ามีลูกทีมคนอื่นๆกรอกเลขนี้ไปแล้วระบบก็จะต้องคำนวณยอดที่ยังสามารถรับได้ของเลขนั้น แบบ realtime
เลขไหนจ่ายเต็ม จ่ายครึ่งก็จะต้องมีขึ้นบอก และเลขไหนอั้นไม่รับก็จะมีแจ้งบอกให้ลบเลขนั้นออก
และมีหมายเหตุให้ใส่ มีปุ่มให้กดว่าจ่ายมาแล้วหรือยังไม่จ่าย
ถ้ากด "ออกบิล" ก็จะแสดงบิลแบบ preview ให้ดู และสามารถกด "โหลดบิล" แบบรูปภาพได้ 
แล้วถ้ากดยืนยัน ก็คือจะลงฐานข้อมูลทันทีว่าสมาชิกคนไหนเป็นคนคีย์เข้ามา ลูกค้าเป็นใคร ซื้อเลขอะไรบ้าง เลขแต่ละเลขซื้อประเภทอะไร มีอัตราจ่ายเท่าไหร่
แล้วก็จะแสดงหน้าตาสรุปรายละเอียดบิลที่หน้าระบบให้เห็น และสามารถกด "โหลดบิล" แบบรูปภาพได้ ถ้ากด "โหลดบิล" ก็จะเป็นการทำบิลนั้นให้กลายเป็นรูปภาพแล้วโหลดลงเครื่องทันที
แล้วรายการบิลนี้ก็จะถูกส่งข้อความ Rich Message ไปหา Line หัวหน้าเพื่อแจ้งให้หัวทราบว่ามีลูกค้าของสมาชิกคนนี้ซื้อเข้ามา และสามารถกดเข้าไปดูในบิลได้จาก Rich Message นั้นแหล่ะว่ามีรายละเอียดการซื้ออะไรบ้าง
การทำงานจะเป็นประมาณนี้

เมนู : สรุปบิล
การทำงานนี้จะมีสองแบบ
หัวหน้า : จะสามารถดูบิลทั้งหมดภายภายในห้องได้ ดูยอดค้างจ่ายทั้งหมดได้ของทั้งสมาชิก ลูกค้า ดูยอดกำไรของแต่ละงวดได้ดูย้อนหลังได้หมดทุกงวด สามารถอัปเดทว่าบิลนั้นลูกค้าจ่ายไปถึงใครแล้ว จ่ายให้ทสมาชิกแล้ว หรือจ่ายไปถึงหัวหน้าแล้ว
ระดับการจ่ายจะเป็นระดับแบบนี้ของแต่ละบิล (ลูกค้า -> ลูกทีม -> หัว) หรือ (ลูกค้า -> หัว)
สามารถดูได้ว่าคนในทีมของตัวเองทั้งหมดจะได้ส่วนแบ่งเท่าไหร่แต่ละคนได้ยอดขายเท่าไหร่ในแต่ละงวดแต่ละหวย
และบิลไหนที่ถูกรางวัล -> หัวหน้าก็จะต้องโอนเงินให้สมาชิกหรือโอนไปให้ลูกค้าเองโดยตรงเลย อันนี้ก็จะต้องมี สถานะของการจ่ายเงินของบิลที่ถูกรางวัลด้วยสามารถอัปเดทสถานะได้ มีให้แนบสลิป

สมาชิก : สามารถดูได้ว่าในแต่ละงวดมีบิลไหนบ้างที่ตัวเองเป็นคนขายได้ และในแต่ละบิลสามารถอัปเดทได้ว่าลูกค้าจ่ายให้ตัวเองไปแล้วหรือยังไม่จ่าย เพื่อให้ทั้งตัวเองและหัวหน้ารู้ว่าบิลนั้นๆได้จ่ายหรือค้างจ่ายอยู่ สามารถดูได้ว่ายอดที่ตัวเองทำได้ในแต่ละงวดขายได้เท่าไหร่
และบิลไหนที่ถูกรางวัล -> สสมาชิกได้โอนไปให้ลูกค้าแล้วหรือยัง อันนี้ก็จะต้องมี สถานะของการจ่ายเงินของบิลที่ถูกรางวัลด้วยสามารถอัปเดทสถานะได้ มีให้แนบสลิป
ย้ำว่าสมาชิกดูและอัปเดทสถานะได้แค่เฉพาะบิลของตัวเองเท่านั้น

เมนู : ตั้งค่า
เฉพาะ หัวหน้าเท่านั้น
- เอาไว้ตั้งค่าอัตราจ่าย ว่าหวยแต่ละประเภทมีอัตราจ่ายบาทละเท่าไหร่ 
- สามารถกำหนดได้ว่าเลขไหนจ่ายครึ่งในงวดนั้นๆ 
- สามารถกำหนดได้ว่าเลขไหนไม่รับ
- สามารถกำหนดยอดที่รับซื้อได้ของแต่ละเลขได้ว่า สามารถรับซื้อได้เท่าไหร่กี่บาทของแต่ละเลข
- เอาไว้ตั้งค่า % ส่วนแบ่งของลูกทีม % แยกตามประเภทหวยที่ขายได้
- ตั้งค่าได้ว่าจะขายหวยอะไร ไทย , ลาว
- ตั้งค่าเวลาปิดรับแต่ละหวยได้


Admin 
- สามารถยืนยันขอสร้างห้องได้ 
- สามารถกำหนดระยะเวลาของแต่ละห้องได้ว่าสามารถใช้ห้องคีย์ได้ตั้งแต่วันไหนถึงวันไหน
- สามารถกำหนดวันเวลาในการไป Scraper เพื่อไปดึงเลขจากเว็บที่กำหนดไว้ได้ 
- สามารถปิดห้องได้ หรือ แตะสมาชิกคนไหนของใครออกจากห้องก็ได้
- สามารถดู report ของแต่ละเจ้าได้

ระบบจะมีประมาณนี้
นายคิดว่ายังไงนายคิดว่าระบบจะใหญ่ไปมั้ย
สามารถทำได้มั้ย
เราว่าจะใน Antigravity ช่วยทำ

และถ้าจะเริ่มทำเราต้องไปเตรียมอะไรก่อนบ้างพวก Line OA ก่อนมั้ย หรือเราต้องไปออกแบบ Rich Menu ก่อนมั้ยของแต่ละแบบ user
และนายลองสรุปสิ่งที่เราต้องการในแบบที่นายเข้าใจมาให้หน่อยขอแบบละเอียดเลยนะขอครบทุก function การทำงานเลยละเอียดมากๆ 

หรือช่วงเริ่มทำไม่ต้องร่วมกับ Line OA จำรองเหตุการไปก่อนเพื่อให้เห็นหน้าระบบก่อนมั้ยแล้วค่อยมัดร่วม line OA ทีหลัง
เน้นย้ำนะต้องรองรับบนมือถือและ desktop ด้วย
และ UI ต้องใช้งานง่ายสะดวก
นายพอจะเข้าใจที่เราอยากทำมั้ย คิดว่ายังไง

และช่วยสร้าง user ที่เป็น role admin ให้หน่อยนะ
และถ้าจะทำเป็น จำลองก่อนแล้วค่อยเอา Line OA มาผูก
ก็จะต้องทำระบบไว้ให้รองรับการปรับง่ายๆด้วยนะ
